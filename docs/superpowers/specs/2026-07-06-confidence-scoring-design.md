# outside-brain — Confidence Scoring Design

**Date:** 2026-07-06  
**Project:** `Projects/PERSONAL/outside-brain`  
**Status:** Design draft — pending Osito review before implementation  

## Purpose

Add a per-conversation confidence score to the chat starters generated by `outside-brain`. The scorer reads each conversation from the `kimi-chat-scraper` archive, compares the user's messages against project-specific keywords, and reports a 0-100 relevance score. Scores are shown in the generated starter under a new "Confidence Scores" section, sorted high-to-low.

## Scope

### In scope
- Read `chat.json` files from `Projects/ACTIVE/kimi-chat-scraper/kimi-chat-archive/`.
- Build a project-specific keyword bag from:
  - Project name words (e.g., "EC8", "Edge", "Crew")
  - Project profile summary words from `kimi-chat-scraper/profiles/<project>.md`
  - Mapped Lares domain names from `config/project_domain_map.json`
- Filter common English stop words.
- Score each conversation by the ratio of unique project keywords found in user messages.
- Render scores in the generated starter markdown.

### Out of scope
- LLM-based classification (requires API calls).
- Complex NLP or TF-IDF weighting.
- Modifying the `kimi-chat-scraper` archive or Lares profile.

## Keyword Sources

For a project like "EC8 Edge Crew" mapped to domains `["betting", "ec"]`:

1. Project name tokens: `ec8`, `edge`, `crew`
2. Profile summary tokens: words from the `## Summary` section
3. Domain name tokens: `betting`, `ec`

Stop words (the, and, for, with, etc.) are removed. Tokens are lowercased and stripped of punctuation.

## Scoring Formula

```
score = (unique_matching_keywords / total_project_keywords) * 100
score = min(score, 100)
```

- Only user messages are scanned.
- A keyword counts once per conversation regardless of repetition.
- Conversations with 0 matches score 0.

## Output Format

A new section in each starter:

```markdown
## Confidence Scores

| Chat | Date | Score | Snippet |
|------|------|-------|---------|
| Edge | 2026-07-03 | 85 | "Edge crew picks for today..." |
| Take the shot | 2026-07-03 | 72 | "Run the edge model on tonight's slate..." |
| ... | ... | ... | ... |
```

Rows are sorted by score descending.
